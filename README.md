# Ccfolia Helper

ccfolia.com 방에서 마커/스크린 패널을 빠르게 생성하고, 즐겨찾기·스탠딩을 관리하는 크롬 확장 프로그램입니다.

---

## 설치 방법

1. 이 저장소의 GitHub 페이지에서 우측 상단 초록색 **Code** 버튼 클릭 → **Download ZIP** 선택
2. 다운로드된 ZIP 파일 압축 해제 (폴더 이름 예: `CCF-Helper-main`)
3. 크롬 주소창에 `chrome://extensions/` 입력
4. 우측 상단 **개발자 모드** 토글 ON
5. **압축 해제된 확장 프로그램 로드** 클릭
6. 압축 해제한 폴더(`CCF-Helper-main`) 선택
7. 확장 프로그램 목록에 나타나면 완료 ✅

> **사이드 패널로 고정하기**: 확장 팝업 오른쪽 상단의 📌 버튼을 누르면 브라우저 사이드 패널에 고정되어 ccfolia를 사용하는 동안 항상 열어둘 수 있습니다.

---

## 사용 방법

### 1. JSON 붙여넣기

아래 형식의 JSON을 클립보드에 복사한 뒤,
ccfolia 방 화면(`https://ccfolia.com/rooms/...`)에서 **입력창 밖**(맵 화면 등)에서 **Ctrl+V** 를 누르면 자동으로 패널이 생성됩니다.

### 2. 팝업 생성기

확장 아이콘 클릭 → **Marker / Screen 탭** → 생성기를 펼쳐 값을 입력 → **JSON 복사** 또는 **즐겨찾기 추가**

### 3. 즐겨찾기

자주 쓰는 패널을 즐겨찾기에 저장해두고 ▶ 버튼으로 바로 생성할 수 있습니다.
폴더 단위로 관리하며, 전체 내보내기/불러오기(JSON)도 지원합니다.

- 항목 이름을 클릭하면 해당 항목의 JSON 데이터가 클립보드에 복사됩니다.
- ✎ 버튼으로 폴더 이름을 인라인 수정할 수 있습니다.
- ✏️ 편집 버튼으로 항목의 이름·크기·이미지 URL 등을 수정할 수 있습니다.
- 편집 폼 하단의 **기본값으로 설정** 버튼을 누르면 해당 항목의 값이 생성기 기본값으로 저장됩니다.
- 이미지 URL이 있는 항목은 썸네일이 표시되며, 썸네일 위에 마우스를 올리면 **큰 이미지 미리보기**가 나타납니다.
- 드래그로 항목 순서를 바꾸거나 다른 폴더로 이동할 수 있습니다.
- 드래그로 폴더 순서도 변경할 수 있습니다.
- 항목·폴더 삭제 시 **3초 동안 실행취소** 버튼이 표시됩니다.

### 4. 우클릭으로 즐겨찾기 추가

ccfolia 맵 위의 **마커/스크린 패널**을 우클릭하면 컨텍스트 메뉴 상단에 **[CCF Helper] 즐겨찾기에 추가** 항목이 표시됩니다.
클릭하면 해당 패널이 즐겨찾기 기본 폴더에 즉시 저장됩니다.

- **앞면·뒷면 모두 지원합니다.** 카드덱 등으로 뒤집힌 패널도 우클릭으로 캡처됩니다.

### 5. 기본값 설정

팝업 생성기의 **기본값 설정** 섹션에서 크기·이미지 URL·각종 옵션의 초기값을 저장할 수 있습니다.
다음 번 팝업을 열었을 때 저장한 값이 자동으로 채워집니다.

### 6. 스탠딩(face) 관리 · 스탠딩 팩

확장 팝업의 **✦ 스탠딩** 탭에서 캐릭터의 스탠딩 이미지를 관리합니다.

#### 캐릭터 자동 감지

ccfolia에서 캐릭터 **편집(Edit) 다이얼로그**를 열면 스탠딩 탭이 **자동으로** 해당 캐릭터를 감지합니다.
감지된 캐릭터 이름이 탭 상단에 표시됩니다.

#### 스탠딩 이미지 추가

- **파일에서 추가** 버튼 또는 버튼 영역에 이미지 파일을 **드래그 앤 드롭**하면 ccfolia에 업로드 후 캐릭터의 face에 일괄 추가됩니다.
- 파일 이름(확장자 제외)이 face 이름으로 저장됩니다. `@` 없이 저장된 이름은 `@` 없이 추가됩니다.
- 같은 이름의 face가 이미 있으면 `(1)`, `(2)` ... 를 붙여 중복을 방지합니다.

> **이미지 보안**: 이미지는 ccfolia 자체 서버(`ccfolia-160aa.cloudfunctions.net`)에 업로드되며, 내 계정(`users/{userId}/files/`) 하위에 저장됩니다. CCF-Helper가 이미지를 별도로 수집하거나 외부로 전송하지 않습니다.

#### 스탠딩 팩

스탠딩 팩은 자주 사용하는 스탠딩 이미지 세트를 이름을 붙여 저장해두는 기능입니다.

- **현재 스탠딩 저장**: EDIT 중인 캐릭터의 스탠딩(face) 목록 전체를 팩으로 저장합니다.
- **+ 팩 만들기**: 빈 팩을 생성하고 이름을 입력합니다 (인라인 입력, 팝업 없음).
- **팩 헤더 드래그**: 팩 전체를 드래그하여 팩 간 순서를 변경합니다.
- **▶ (전체 적용)**: 팩의 모든 스탠딩을 현재 캐릭터에 한 번에 추가합니다.
- 팩 이름 옆 **✎** 버튼으로 팩 이름을 인라인 수정합니다.
- **내보내기 / 불러오기**: 팩 전체를 JSON 파일로 백업하거나 복원합니다.

#### 팩 내 항목 관리

- 썸네일 이미지 위에 마우스를 올리면 **큰 이미지 미리보기**가 나타납니다.
- 항목을 **드래그**하여 팩 내 순서를 변경합니다.
- 항목 옆 **✎** 버튼으로 이름을 인라인 수정합니다.
- **▶** 버튼으로 해당 항목만 현재 캐릭터에 적용합니다.
- **✕** 버튼으로 삭제 (3초 동안 실행취소 가능).
- `+ URL 추가`로 이미지 URL과 이름을 직접 입력해 팩에 추가합니다.

## JSON 형식

### 마커 패널

```json
{
  "type": "marker",
  "memo": "마커 설명",
  "width": 2,
  "height": 2,
  "overlapPriority": 1,
  "imageUrl": "https://example.com/image.png",
  "fixedPlacement": false,
  "fixedSize": false,
  "clickAction": "sendToChat",
  "clickActionText": "채팅으로 보낼 내용"
}
```

### 스크린 패널

```json
{
  "type": "screen",
  "memo": "스크린 설명",
  "width": 4,
  "height": 4,
  "overlapPriority": 1,
  "imageUrl": "https://example.com/front.png",
  "coverImageUrl": "https://example.com/back.png",
  "fixedPlacement": false,
  "fixedSize": false,
  "asPlanePanel": false,
  "clickAction": "sendToChat",
  "clickActionText": "채팅으로 보낼 내용"
}
```

### 필드 설명

| 필드 | 필수 여부 | 기본값 | 설명 |
|---|---|---|---|
| memo | ✅ 필수 | 없음 | 패널 설명 (줄바꿈은 `\n`) |
| type | 선택 | `marker` | `marker` 또는 `screen` |
| width | 선택 | 마커 2 / 스크린 4 | 폭 |
| height | 선택 | 마커 2 / 스크린 4 | 높이 |
| overlapPriority | 선택 | `1` | 겹침 우선도 |
| imageUrl | 선택 | `null` | 패널 앞면 이미지 URL |
| coverImageUrl | 선택 | `null` | 패널 뒷면 이미지 URL (스크린 전용) |
| fixedPlacement | 선택 | `false` | `true`이면 위치 고정 |
| fixedSize | 선택 | `false` | `true`이면 크기 고정 |
| asPlanePanel | 선택 | `false` | `true`이면 단축키 비활성화 (스크린 전용) |
| clickAction | 선택 | `none` | `none` 또는 `sendToChat` |
| clickActionText | 선택 | 없음 | `sendToChat`일 때 보낼 텍스트 |

### 최소 예시 (memo만 있어도 동작)

`type`을 생략하면 기본값인 **마커 패널**로 생성됩니다.

```json
{
  "memo": "이것은 마커입니다"
}
```

---

## 기타

- **입력창 안**에서 붙여넣기하면 동작하지 않습니다 (일반 타이핑 방해 안 함).
- JSON 형식이 아니거나 `memo` 필드가 없으면 동작하지 않습니다.

## 변경 이력

### v2.0.0

#### 스탠딩 탭 UX 전면 개편

- **EDIT 다이얼로그 열면 자동 감지**: ccfolia에서 캐릭터 편집을 열면 스탠딩 탭이 즉시 감지·업데이트 (재클릭 불필요)
- **팩 순서 드래그**: 팩 헤더를 드래그하여 팩 간 순서 변경 가능
- **팩 내 항목 드래그**: 팩 내 스탠딩 항목을 드래그하여 순서 변경
- **인라인 이름 수정**: 팩 이름(✎), 팩 내 항목 이름(✎)을 팝업 없이 UI에서 바로 수정
- **삭제 실행취소**: 팩·팩 항목 삭제 시 3초 동안 실행취소 가능 (즐겨찾기 항목·폴더도 동일)
- **이미지 미리보기**: 썸네일 위에 마우스를 올리면 큰 이미지가 플로팅으로 표시 (즐겨찾기·스탠딩 팩 공통)
- **파일 드래그 앤 드롭**: 파일에서 추가 버튼 영역에 이미지 파일을 드래그해서 바로 업로드
- **팩 내보내기 / 불러오기**: JSON 파일로 팩 전체 백업·복원
- **인라인 새 팩 만들기**: 팩 이름 입력을 UI 내 인라인 폼으로 처리 (prompt() 제거)
- **버튼 스타일 통일**: 팩 내 항목 버튼(✎ / ▶ / ✕)을 즐겨찾기 버튼과 동일한 테두리 없는 아이콘 스타일로 통일
- **@ 접두사 보존**: `@` 없이 저장된 스탠딩 이름은 적용 시에도 `@` 없이 그대로 사용

#### 즐겨찾기

- **폴더 인라인 이름 수정**: ✎ 버튼으로 팝업 없이 폴더 이름 수정

#### 버그 수정

- 숫자만으로 된 캐릭터 이름 감지 불가 문제 수정 (MuiTypography span 직접 읽기)
- EDIT 다이얼로그 열 때 authToken이 없으면 face 수가 0으로 표시되던 문제 수정
- 사이드 패널 우측 빈 공간 문제 수정 (body width 100% 고정)
- 캐릭터 전환 시 캐시 불일치로 잘못된 캐릭터가 감지되던 문제 수정
